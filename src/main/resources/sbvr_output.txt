Es ist notwendig, dass der Prozess mit dem StartEvent 'Signed employment 
contract on file' startet.
Es ist notwendig, dass 'Human Resources Department' 'Add personal data' ausführt, wenn 'Human Resources Department' 'Start' ausführt.

Es ist notwendig, dass 'Procurement' 'Procure work equipment' ausführt und 'IT-Department' 'Set up access rights, hardware and software' ausführt, wenn 'UND-Gateway' mit der Bedingung 'unbekannte Bedingung' und 'unbekannte Bedingung' erfüllt ist.
Es ist notwendig, dass 'Human Resources Department' 'Select necessary work equipment' ausführt, wenn 'Human Resources Department' 'Add personal data' ausführt.

Es ist notwendig, dass die Aktivitäten 'Set up access rights, hardware and software' und 'UND-Gateway' ausgeführt werden, wenn das AND Gateway 'Unbenanntes AND Gateway' aktiv ist und alle eingehenden Pfade abgeschlossen sind.

Es ist notwendig, dass 'Procurement' den Subprozess 'Procure work equipment' ausführt, wenn 'Human Resources Department' 'UND-Gateway' aktiv ist und alle eingehenden Pfade abgeschlossen sind.


It is obligatory that 'employment contract' is produced when 'Add personal data.
It is obligatory that 'Select necessary work equipment' only if 'Work equipment' is provided to lane.
It is obligatory that 'Procure work equipment' only if 'Work equipment' is provided to lane.

Es ist notwendig, dass die TextAnnotation 'Personnel System' der Aktivität 'Add personal data' zugeordnet ist.
Es ist notwendig, dass die TextAnnotation 'Personnel System' der Aktivität 'Set up access rights, hardware and software' zugeordnet ist.


Es ist notwendig, dass der Subprozess 'Procure work equipment' die Nachricht Unbekannte Nachricht' vom Supplier empfängt.
Es ist notwendig, dass der Subprozess 'Procure work equipment' die Nachricht 'Unbekannte Nachricht' an Supplier' sendet.
Es ist notwendig, dass der Prozess mit dem EndEvent 'Prepared for  employee to start' endet, nachdem die Aktivität 'unbenannte Aktivität' abgeschlossen wurde.
